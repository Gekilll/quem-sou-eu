## 📖 Sobre o projeto

Este projeto nasceu como um exercício prático de desenvolvimento web para praticar a estrutura básica de uma página e a estilização com CSS. A página é estática: não usa JavaScript, frameworks nem dependências externas.

## 🧩 Seções da página

- **Quem sou eu?**: título de abertura com uma imagem de destaque.
- **Um pouco sobre mim**: breve apresentação pessoal.
- **Sites que eu gosto de acessar**: lista de imagens clicáveis que levam aos sites favoritos (Medalhei, YouTube e YouTube Music).
- **Algumas preferências minhas**: tabela com meus interesses (animes, futebol e jogos) e o motivo de gostar de cada um.

## 🛠️ Tecnologias e conceitos praticados

- HTML5 semântico (títulos, parágrafos, listas, tabelas, links e imagens)
- CSS3 (cores, bordas arredondadas, margens e espaçamentos)
- Flexbox para organizar a lista de sites e a tabela
- Favicon e título personalizados da aba

## 🚀 Como executar

Como o projeto é estático, não precisa instalar nada.

```bash
# Clone o repositório
git clone https://github.com/Gekilll/quem-sou-eu.git

# Entre na pasta
cd quem-sou-eu
```

Depois, abra o arquivo `index.html` no seu navegador (dois cliques nele ou botão direito → *Abrir com* → navegador).

Se preferir, use a extensão **Live Server** do VS Code: clique com o botão direito em `index.html` e escolha *Open with Live Server*.
