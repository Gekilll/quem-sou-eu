## 📖 Sobre o projeto

O objetivo do projeto é praticar a construção e a apresentação de uma página web com HTML e CSS, utilizando o Bootstrap para auxiliar na organização dos componentes e na adaptação do layout a diferentes tamanhos de tela.

A página é estática e não utiliza JavaScript próprio. O Bootstrap 5 é carregado por meio de uma CDN, portanto é necessária uma conexão com a internet para carregar a folha de estilos do framework.

## 🧩 Seções da página

- **Quem sou eu?** — apresentação pessoal e imagem de destaque.
- **Sites que gosto de acessar** — imagens clicáveis que levam ao Medalhei, YouTube e YouTube Music.
- **Algumas preferências minhas** — tabela com interesses pessoais e os motivos pelos quais gosto deles.

## 🛠️ Tecnologias e recursos

- **HTML5** para estruturar o conteúdo.
- **CSS3** para personalizar cores, espaçamentos, bordas e o layout.
- **Bootstrap 5** para utilizar componentes e classes utilitárias, como cards, sistema de grid e estilos de tabela.
- **Media queries** para ajustar a apresentação em telas menores.
- **GitHub Pages** para publicar a página.

## 📱 Responsividade

O projeto inclui regras CSS para diferentes larguras de tela:

- Até `768px`: ajustes para tablets e telas menores.
- Até `576px`: ajustes adicionais para celulares.

A página também utiliza classes responsivas do Bootstrap, como `container`, `py-md-5`, `col-md-*` e `img-fluid`.

## 🚀 Como executar localmente

Não é necessário instalar dependências para abrir a página.

```bash
# Clone o repositório
git clone https://github.com/Gekilll/quem-sou-eu.git

# Entre na pasta do projeto
cd quem-sou-eu
```

Depois, abra o arquivo `index.html` em um navegador. Se preferir, utilize a extensão **Live Server** no Visual Studio Code para visualizar a página enquanto desenvolve.
